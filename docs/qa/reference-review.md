# Orbit current-reference review

Reviewed: 2026-08-28

Orbit is a private professional relationship instrument for Charlie. Its single job is to show who matters and make the next action legible. The design therefore treats the network as a quiet cartographic field anchored by the self diamond, with ledger-like information rails around it. Reference implementations informed composition and state ownership; no source was copied and no reference package was installed.

## Applied boundary

- Adopted: semantic state composition, primitive-owned focus and dismissal, causal mount/unmount continuity, dense panel rhythm, measured overflow, and a scrollable control rail.
- Rejected: decorative motion, generic card grids, nested floating surfaces, glass effects, gradients, oversized radii, stacked shadows, and animation that competes with the relationship topology.
- Orbit-specific risk: the warm off-white palette could drift into a generic cream-and-serif treatment. The exact brief colors are retained, while system UI typography, compact ledger rails, and the cardless graph field keep the product operational rather than editorial.
